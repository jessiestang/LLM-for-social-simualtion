## Layout of the validation module

The validation module consists of the following LLM agents in the file `validator.py`:

* Evaluation strategy suggester (`evaluation_suggestion`): Reads a conceptual model JSON and proposes four VVUQ strategies — stochasticity control, parameter sensitivity analysis, uncertainty quantification, and cross-condition comparison.
* Evaluation code generator (`evaluation_code_generator`): Takes the evaluation suggestions and a model interface JSON and generates a runnable Python evaluation script without modifying any model internals.

## Input & output of case studies

Two case studies are included. Each uses JSON files produced by earlier modules as inputs and outputs a runnable Python evaluation script.

### Input — conceptual models and model interfaces

The validation module does not have its own input files. It reads outputs produced by the upstream modules.

### Output — generated evaluation code


| File                                | Case study            | Description                                                                                                                                                                                                                              |
| ----------------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `stochasticity_schelling.py`        | Schelling Segregation | Stochasticity-control evaluation: runs the Schelling model multiple times with different random seeds, computes the segregation index across runs, and assesses output stability via mean and standard deviation.                        |
| `sensitivity_analysis_schelling.py` | Schelling Segregation | Parameter sensitivity analysis: varies the homogeneity preference threshold across its defined range, runs multiple iterations per value, and measures the effect on agent movement and segregation outcomes.                            |
| `spiral_silence_evaluation_code.py` | Spiral of Silence     | Sensitivity analysis for the Spiral of Silence model: sweeps the`beta` parameter (weight of perceived public opinion) across its range, running multiple simulation iterations per value and tracking the proportion of speaking agents. |

Folder `output_plots` contains the output plots generated by the evaluation scripts.
